# Trust Layer

## الهدف

أي طريق أو تكلفة أو بلاغ لازم يجاوب على سؤال المستخدم: **المعلومة منين؟**

بدون طبقة ثقة، المستخدم قد يستخدم النتيجة لنفسه لكنه لن يشارك الرابط بثقة مع الجروب.

## ما تمت إضافته

### مؤشرات ظاهرة للمستخدم

- آخر تحديث منذ X دقائق.
- تم تأكيده بواسطة X مستخدم.
- ثقة عالية / متوسطة / تحتاج تأكيد.
- عدد تأكيدات السعر.
- عدد تأكيدات أن الخط يعمل الآن.
- أسئلة تصويت مباشرة:
  - هل السعر صحيح؟ نعم / لا
  - هل الخط يعمل الآن؟ شغال / واقف
  - هل الطريق صحيح؟ صحيح / غير دقيق

### أماكن الظهور

- نتائج `/planner` قبل مشاركة واتساب.
- صفحات المناطق `/areas/:slug` لزيادة ثقة المجتمع المحلي.

### قاعدة البيانات

تمت إضافة جدول:

```sql
route_trust_votes
```

ويخزن:

- نوع التصويت.
- route / area / station / line.
- المستخدم إن وجد، أو مساهمة anonymous.
- وقت التصويت.

### Growth tracking

تمت إضافة event:

```txt
trust_feedback_created
```

حتى نعرف هل طبقة الثقة تجعل الناس تؤكد وتشارك أكثر.

## لماذا هذا مهم للنمو؟

المشاركة تحتاج ثقة. عندما يرى المستخدم:

> آخر تحديث منذ 8 دقائق — تم تأكيده بواسطة 12 مستخدم — ثقة عالية

سيكون أسهل عليه إرسال الرابط على واتساب بدون خوف من إحراج أو معلومة غلط.
